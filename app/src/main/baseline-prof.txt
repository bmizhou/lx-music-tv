# Baseline Profile（手写规则，随 APK 编译进 assets/dexopt/baseline.prof）
#
# 作用：让下列热路径（启动 + 各主屏组合 + Compose Lazy 列表滚动 + 图片解码 + 播放/搜索）
# 在 Android TV 上获得 AOT 预热，缓解首启与上下切歌单 / 滚动时的掉帧。
#
# 格式（profman 标准语法，非 workaround）：
#   - 类规则：裸 `L<类>;` —— 整类纳入预热，【绝不可带 H/S/P 标志】（类规则不支持标志是语法铁律）。
#   - 方法规则：`<标记><类>-><方法>(<参数>)<返回>`，标记可用 H/S/P（如 HSPLcom/foo/Bar;->baz()V）。
# 本文件统一用裸类规则（稳健、零误报）。
#
# 历史：旧 Compose BOM 合并后曾产出带 H/S/P 标志的畸形类规则，导致
# `Error parsing baseline-prof.txt: Class rules don't support flags`；当时靠
# build.gradle.kts 里的 fixMergedBaselineProfile 补丁任务规避。
# 现状（AGP 9.3）：合并已不再产生畸形类规则，该补丁任务已删除；
# 由 androidx.profileinstaller:1.4.1 在运行时下发 profile，手写规则直接生效。
